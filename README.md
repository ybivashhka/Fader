# Fader

<img src="docs/icon.png" width="72" alt="Fader">

Громкость приложений на Mac. Музыку громче, браузер тише — из одного окна.

**macOS 14.2+ · Apple Silicon**

## Установка

1. Скачайте [**Fader-0.1-macOS.zip**](https://github.com/ybivashhka/Fader/releases/download/v0.1/Fader-0.1-macOS.zip) из **Releases**.
2. Распакуйте и перенесите **Fader.app** в **Программы**.
3. Откройте Fader, нажмите **«Включить микшер»** и разрешите доступ к системному звуку.

Сборка пока не нотарифицирована Apple. Если macOS блокирует запуск, смотрите [инструкцию Apple](https://support.apple.com/ru-ru/102445).

## Как пользоваться

Запустите музыку или видео — приложение появится в списке.

- Ползунок меняет громкость приложения.
- Кнопка динамика выключает звук.
- Нажатие на процент возвращает 100%.
- Вверху можно выбрать аудиовыход и общую громкость.

Уровни сохраняются. Закрыли окно — Fader остаётся в строке меню. Кнопка питания возвращает обычный звук.

Один ползунок браузера управляет всеми его вкладками.

Звук обрабатывается на Mac, без записи и отправки в интернет.

## Сборка

Нужны Xcode Command Line Tools:

```sh
zsh build.sh
```

Готовое **Fader.app** появится рядом с папкой исходников.
